Internship · ScreenEdge Africa

ScreenEdge, AML/CFT sanctions & PEP screening

Problem. African obliged entities must screen sanctions and politically exposed persons, report to authorities (CNASNU, CENTIF, CTAF, ANIF) and prove compliance at any time, across names written in Arabic, Cyrillic or African languages.

Built. A cross-script matching engine (Jaro-Winkler, sentence-transformers, adaptive weighting), a PEP collection agent that reads official sources, including protected ones, and a PEP qualification agent that checks each person against a country repository (official functions, local law, FATF status) to cut false positives.

Result. 204 qualified PEPs, 90.8% recall on a 105-case multilingual dataset, 31,500+ candidates collected automatically in 6 hours.

LLM evaluation · Open source

French AI response evaluation rubric

Problem. Judging AI answers by gut feeling is not reproducible, and a good average can hide a serious safety breach.

Built. A weighted rubric on 5 criteria (accuracy 30%, instruction following 25%, relevance 20%, clarity 15%, safety 10%), a critical-failure rule that overrides the score, 10 synthetic cases with improved responses, and a Python script that recomputes every score.

Result. Fully reproducible checks: one command validates every score and every critical-failure verdict.

Academic project · PACTE, HESTIM

SENTINEL, port anomaly detection

Problem. Detect fires, gas leaks or intrusions in port warehouses before they become dangerous.

Built. An Isolation Forest pipeline over 9 simulated IoT sensors in 3 warehouses (ESP32, MQTT, Raspberry Pi), 6 anomaly scenarios injected into 405,171 real measurements, InfluxDB Cloud storage and a Flask dashboard with role-based access and an injection simulator.

Result. 96.8% average recall across the 6 scenarios, above the 90% target taken from IEC 61511 SIL 1.
